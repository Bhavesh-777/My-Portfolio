Front-End Devlopement

A Front-End Developer is someone who creates websites and web applications.

Front-End refers to how a web page looks. You can think of Front-End as client-side and Back-End as server-side.

The basic languages are : HTML, CSS, and JavaScript Etc.

Back-End Devlopement

A backend developer is responsible for writing APIs, designing libraries, improving data architecture, and communicating with the database.

The basic languages are : Java , Python and .Net Etc.

Full Stack Devlopement

A full stack web developer is a person who can develop both client and server software.
